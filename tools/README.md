# 🛠️ Инструменты для работы с памятью Джарвиса

Этот каталог содержит утилиты для просмотра и управления базой данных памяти Джарвиса.

## 📋 Доступные инструменты

### 1. 🖥️ Console Inspector (`inspect_db.py`)

Консольный инструмент для быстрого просмотра всех воспоминаний в виде таблицы.

**Использование:**
```bash
# Из корневой директории проекта
python3 tools/inspect_db.py

# Или напрямую (если скрипт исполняемый)
./tools/inspect_db.py
```

**Что показывает:**
- Общее количество записей в базе
- Таблицу со всеми воспоминаниями (ID, текст, метаданные)
- Путь к базе данных и название коллекции

**Пример вывода:**
```
====================================================================================================
📚 БАЗА ДАННЫХ ДЖАРВИСА: jarvis_memory
📍 Путь: data/vector_db
📊 Всего записей: 5
====================================================================================================

+-----+-------------+-----------------------------+----------------+
|   № | ID          | Текст                       | Метаданные     |
+=====+=============+=============================+================+
|   1 | 5ededb36... | Босс любит кофе по утрам... | —              |
+-----+-------------+-----------------------------+----------------+
```

### 2. 🌐 Web Dashboard (`memory_dashboard.py`)

Интерактивный веб-интерфейс на базе Streamlit для работы с памятью.

**Использование:**
```bash
# Из корневой директории проекта
streamlit run tools/memory_dashboard.py

# Или с указанием порта
streamlit run tools/memory_dashboard.py --server.port 8501
```

**Возможности:**
- 📊 **Статистика**: Общее количество воспоминаний, название коллекции, путь к БД
- 🔍 **Семантический поиск**: Поиск по смыслу запроса (не по ключевым словам!)
- 📚 **Просмотр всех записей**: Полный список воспоминаний с возможностью фильтрации
- 🎯 **Релевантность**: Показывает степень соответствия результатов поиска

**Пример использования поиска:**
1. Введите запрос: "что ты знаешь о моих предпочтениях?"
2. Выберите количество результатов (1-10)
3. Получите самые релевантные воспоминания с процентом соответствия

**Скриншот интерфейса:**

## 🚀 Быстрый старт

### Установка зависимостей

Все необходимые зависимости уже должны быть установлены. Если нет:

```bash
pip install streamlit tabulate chromadb sentence-transformers
```

### Проверка работы

1. **Консольный просмотр:**
   ```bash
   python3 tools/inspect_db.py
   ```

2. **Веб-интерфейс:**
   ```bash
   streamlit run tools/memory_dashboard.py
   ```
   Откроется браузер на `http://localhost:8501`

---

## 📝 Примечания

- **Семантический поиск**: Оба инструмента используют ту же модель эмбеддингов (`all-MiniLM-L6-v2`), что и основной MemoryManager
- **Производительность**: Первый запуск может занять время из-за загрузки модели
- **База данных**: Инструменты работают в режиме только для чтения, не изменяют данные
- **Конфигурация**: Все настройки берутся из `config/settings.py`

---

## 🔧 Технические детали

### Используемые технологии:
- **ChromaDB**: Векторная база данных
- **Streamlit**: Веб-фреймворк для дашборда
- **Tabulate**: Форматирование таблиц в консоли
- **Sentence Transformers**: Модель эмбеддингов

### Структура данных:
- **ID**: Уникальный идентификатор (UUID)
- **Document**: Текст воспоминания
- **Metadata**: Дополнительные данные (опционально)
- **Embedding**: Векторное представление (скрыто от пользователя)

## 🐛 Troubleshooting

**Проблема**: `ModuleNotFoundError: No module named 'streamlit'`
```bash
pip install streamlit
```

**Проблема**: База данных пуста
- Убедитесь, что Джарвис уже сохранил хотя бы одно воспоминание
- Проверьте путь к БД в `config/settings.py`

**Проблема**: Streamlit не открывается в браузере
```bash
streamlit run tools/memory_dashboard.py --server.headless false
```
